## Abrir no Obsidian
1. Clone ou baixe este repositório.
2. Abra a pasta como um vault.
3. Em Settings → Files and links, ative **Use Wikilinks**.
4. Abra `00 - Inicio/Inicio.md`.
5. Explore Graph view.

> GitHub não interpreta wikilinks nativamente. Eles são destinados ao Obsidian.

## Princípios
- Capture primeiro; organize depois.
- Uma nota deve representar uma ideia clara.
- Prefira links com contexto.
- MOCs são mapas de navegação, não depósitos de links.
- Revise e conecte notas antigas.
