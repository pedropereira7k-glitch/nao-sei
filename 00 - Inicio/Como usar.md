# Como usar

## Fluxo
1. **Capturar:** registre ideias na [[00 - Inicio/Inbox|Inbox]].
2. **Processar:** decida se é ação, referência, conhecimento ou descarte.
3. **Escrever:** uma nota deve desenvolver uma ideia principal com suas palavras.
4. **Conectar:** use `[[Nome da nota]]`; para rótulo personalizado, `[[Nome da nota|texto]]`.
5. **Mapear:** atualize o MOC da área.
6. **Revisar:** processe a Inbox e melhore notas antigas semanalmente.

## MOCs
MOC significa *Map of Content*. É um mapa de navegação que agrupa notas e explica como elas se relacionam. Não é uma lista indiscriminada.

## Obsidian
Abra a pasta como vault. Em Settings → Files and links, ative **Use Wikilinks**. Use Graph view para explorar as conexões.

## Evite
- Criar estrutura excessiva antes de ter conteúdo.
- Copiar material sem elaborar.
- Criar links só para enfeitar o grafo.
- Confundir quantidade de notas com aprendizado.
